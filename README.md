# Assignment 1: HTML and CSS Basics

This project completes Tasks 1–5 of the frontend assignment. It has five linked webpages, shared CSS styling, a responsive personal profile page, a float-based layout, a tribute page, a table and feedback form, and a midterm website concept with sitemap and wireframes.

## Before submitting

1. In `index.html` and `task4.html`, replace `YOUR NAME` and `YOUR GROUP` with your own details.
2. Replace `profile.svg` with your own photo before submitting. Keep the same filename, or update the image path in `index.html`.
3. Open `index.html` in a browser and check every navigation link.
4. Upload every file in this folder to a GitHub repository.
5. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, select `main` and `/ (root)`, then save. Submit the repository link and your GitHub Pages link.

## File guide

- `index.html` — Task 1, personal profile webpage
- `task2.html` — Task 2, layout made with floats
- `task3.html` — Task 3, Ada Lovelace tribute page
- `task4.html` — Task 4, grades table and feedback form
- `task5.html` — Task 5, midterm topic, sitemap, and wireframes
- `styles.css` — shared styling for all pages
